# 快速检查清单

## 接口对齐检查

生成规格或实现接口时，逐项核对：

- path
- HTTP method
- query 参数
- body 结构
- 字段名
- 字段类型
- 是否可空
- 分页结构
- 状态值
- 错误消息
- 国际化消息键

补充规则：

- 真实后端路径禁止默认加 `/api` 前缀
- 分页结构以后端标准 `PageResult` 为准
- 如果 mock 分页结构不同，要标记为 mock 偏差，不要直接照抄

## 后端开发硬规则

- 严格按当前模块已确认规格开发
- 只能依据事实源和已确认规则编码
- 不允许猜测
- 不允许新增前端未定义必填字段
- 不允许省略前端已定义字段
- 不允许用占位实现代替真实实现
- 不允许跳过 TDD
- 不允许跳过双重审查
- 不允许跳过 smoke test
- 数据库更新脚本必须写入 `ht-starter.js`
- controller 接口方法禁止使用 `@OpenApi`

## 常用汇报结构

### 规格阶段

- 当前模块
- 当前阶段：spec
- 已生成哪些规格文档
- 审查结果
- 是否存在阻塞
- 下一步

### 开发阶段

- 当前模块
- 当前任务
- 写了哪些测试
- 跑了哪些测试
- 是否通过
- 做了哪些实现
- 做了哪些审查
- 执行了哪些 curl smoke test
- 是否阻塞
- 下一步
